# Awesome ASCII Animation [![Awesome](https://awesome.re/badge-flat.svg)](https://awesome.re)

> A curated list of ASCII art animation tools, generators, converters, and resources.

ASCII animation turns characters and symbols into moving art — from old-school BBS demos to modern browser-based generators. This list covers everything from online tools to libraries and classic demoscene works.

## Online Tools

- [ascii.life](https://ascii.life) - AI-powered ASCII animation generator. Convert text prompts, images, audio, or video to animated ASCII art with 12 retro display themes (Matrix, CRT, C64, DOS, Apple II, Amber, Phosphor, Plasma, VFD, LCD). Export as GIF or MP4. MIT-licensed public gallery.
- [ASCIICraft](https://asciicraft.com) - Browser-based converter that turns images, GIFs and videos into ASCII art, with text banners and animated export.
- [asciimation.co.nz](http://www.asciimation.co.nz) - Classic ASCII animation of Star Wars, by Simon Jansen. A landmark in ASCII animation history.
- [Playscii](http://vectorpoem.com/playscii/) - Open source ASCII/ANSI art and animation editor.
- [PabloDraw](http://picoe.ca/products/pablodraw/) - ANSI and ASCII art editor with real-time collaboration.

## CLI Tools

- [libcaca](http://caca.zoy.org/wiki/libcaca) - Color ASCII-art library. Converts images and video to colored ASCII art in the terminal.
- [jp2a](https://github.com/cslarsen/jp2a) - Converts JPEG images to ASCII art.
- [figlet](http://www.figlet.org/) - Generates text banners in ASCII art using various fonts.
- [aalib](http://aa-project.sourceforge.net/) - Portable ASCII art graphics library used to convert images and video.
- [mplayer -vo aa](https://wiki.archlinux.org/title/MPlayer) - Play video as ASCII art in the terminal using MPlayer with the aa video output driver.
- [Carbonyl](https://github.com/fathyb/carbonyl) - Chromium-based browser that renders to ASCII art in a terminal.

## Libraries

- [asciify](https://github.com/ajay-gandhi/asciify) - Node.js library for converting images to ASCII art.
- [Climage](https://github.com/pnappa/CLImage) - Python library to convert images to ASCII art for terminal display.
- [ascii-art](https://www.npmjs.com/package/ascii-art) - Node.js library for generating ASCII art text and image conversions.
- [gif-frames](https://github.com/benwiley4000/gif-frames) - Extract frames from GIF files (useful for ASCII animation pipelines).

## Classic Works

- [Star Wars ASCII](telnet://towel.blinkenlights.nl) - Full Star Wars Episode IV in ASCII art. `telnet towel.blinkenlights.nl`
- [Demoscene ASCII art](https://16colo.rs) - Archive of classic ANSI and ASCII art from BBS era groups (16colo.rs).
- [Textmode art](https://lospec.com/gallery/tag/textmode) - Gallery of modern textmode and ASCII art on Lospec.
